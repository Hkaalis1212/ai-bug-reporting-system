🗂️ Zip File Upload Example

📁 Drop your zip file here or click to browse


💡 How to Use

  1. Select a .zip file using the file input above
  2. Click "Upload Zip File" to start the upload
  3. The file will be uploaded and automatically extracted
  4. You'll see a success message with details about extracted files

🔧 Programmatic Upload (curl)

curl -X POST -F "file=@your-file.zip" http://localhost:5000/upload

🐍 Python Example

import requests

with open('your-file.zip', 'rb') as f:
    files = {'file': ('your-file.zip', f, 'application/zip')}
    response = requests.post('http://localhost:5000/upload', files=files)
    print(response.json())
